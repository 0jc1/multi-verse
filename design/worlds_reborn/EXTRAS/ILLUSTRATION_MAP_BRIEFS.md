# Apeverse — Separate Illustrated Map Generation Briefs

**Purpose:** generate ONE map per location, not a collage, following the owner's existing illustrated Madrid, Pai, Alien Maze, Atlantis, Neon Nexus, Maya and Astro-9 reference images in `../REFERENCE_MAPS/`. These are design images for building worlds, not claim-to-scale street maps. New image creation requires an actual image-generation tool; a 3D coding tool alone cannot guarantee this artwork.

## Universal image style prefix (apply to each world)

**Apeverse illustrated game-world map**: 16:9 wide horizontal travel-poster/top-down isometric illustrated map; extremely detailed lively hand-drawn black-ink outlines with colored pencil, marker and watercolor washes; vivid flower-power psychedelic colors with readable labels, warm off-white hand-lettered location banners, a little headphone-and-sunglasses ape mascot, compass, map legend keyed to transportation and world activities, miniature scenes of people and creatures, winding believable roads and geographic continuity, no photorealism, no app/website screenshots, no PowerPoint layout or collage, original cartographic composition. Use plenty of negative space behind labels; consistent readable spelling. Places must look like the actual era/setting, not generic mixed styles. Always include an *in-world portal*, a neighborhood with meaningful activities, a peaceful natural or residential edge, and several travel paths. Do not fabricate exact walking times or real-world distances.

## Deliverable instructions for map creation
1. Use this universal style plus one world brief per generation; **generate and save separate files** `design/maps/<id>.png` rather than a single board.
2. Keep labels legible; re-render wrong place names. Mark explicitly where a name is unverified (e.g. Pai tea venue, Katina's/Ganita's).
3. Compare every new map with a `design/worlds/<id>.json` map blueprint so roads and locations match. Include the separate in-world minimap drawing data but never simply show the poster as the dynamic minimap.
4. When all new map images are complete, assemble a separate atlas contact sheet as an *optional summary*; the individual map files are the mandatory deliverable.
